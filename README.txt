GPT老师の物料管理器 V2.6.0

新增：互换打包管理
- 互换增加独立“未打包 / 已打包”状态，不影响原交换进度
- 互换页增加“未打包”筛选
- 待交换卡片可直接“一键标记已打包”，无需进入编辑
- 首页待交换卡显示未打包数量，并增加“去处理未打包”入口
- 现场模式仅在未打包时显示醒目提醒；已打包不占空间
- 编辑互换时也可手动修改打包状态
- 完成交换会自动视为已打包
- 旧记录兼容：旧的已完成记录视为已打包，其余待交换记录默认未打包
- Excel 导入导出新增“打包状态”字段

星屿物料 · 个人版 V2.4

本次更新：数据管理

1. 导出 Excel（.xlsx）
- 断网可用，本地生成，不依赖在线服务
- 工作表：场次 / 我的物料 / 互换 / 蹲蹲
- Excel 不嵌入图片，仅记录图片数量
- 包含内部 ID，便于再导回 App

2. 导入 Excel
- 支持本 App 导出的 .xlsx
- 支持 3 种方式：
  A. 新增，不覆盖
  B. 按内部 ID 合并 / 更新
  C. 清空业务数据后导入
- Excel 导回时不会恢复图片（图片需用完整备份）

3. 完整备份 / 恢复
- JSON 格式
- 包含场次、物料、互换、蹲蹲及所有本地图片 DataURL
- 适合换手机 / 换电脑 / 防止数据丢失
- “恢复备份”会替换现有业务数据

测试建议：
- 先录几条数据和图片
- 导出 Excel，确认有 4 个工作表
- 再导出完整备份
- 用“新增”模式导入 Excel 测试
- 如要测试完整恢复，请先保留备份文件
